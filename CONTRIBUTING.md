# Contributing

Issues and focused pull requests are welcome. Explain the user-visible problem, include synthetic examples, and run `npm test` and `npm run build` before submitting. For backend changes, use the disposable local integration suite and check upgrade compatibility.

Do not include real board snapshots, access invitations, keys, user data, or production manifests in issues, screenshots, tests, or pull requests. Keep examples fictional. Changes to permissions or publishing should retain project scoping and make stale or conflicting updates visible.

Contributions are accepted under the repository's FSL-1.1-ALv2 license. Submit only work you have the right to contribute. Do not add a platform-specific Rollup native module as a direct dependency; npm installs the appropriate optional package automatically.
